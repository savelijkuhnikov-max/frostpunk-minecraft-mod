# Frostpunk Minecraft Mod

Hardcore winter survival mod for Minecraft 1.20.1 inspired by the game Frostpunk.

## Features

### 🌨 Blizzard System
- Random blizzards with dynamic intensity
- Extreme visibility reduction during storms
- Movement slowdown effects
- Duration and frequency similar to Frostpunk

### 🌡 Temperature System
- Global world temperature affected by time of day and season
- Realistic temperature drops to -60°C
- Temperature warnings and HUD display
- Affects gameplay mechanics dynamically

### ❄ Frostbite & Hypothermia
- Players take damage in extreme cold without proper equipment
- Movement penalties in freezing conditions
- Hunger increased by cold
- Armour provides warmth protection
- Critical temperature: -40°C causes severe damage

### 🧊 Permafrost System
- Water freezes to ice and packed ice at low temperatures
- Grass blocks freeze into snow
- Expanding ice coverage creates environmental hazards

### 📖 Story Progression
- Dynamic storyline with stages
- Introduction to survival mechanics
- First blizzard warning
- Advanced survival challenges
- Immersive narrative elements

### 🎮 Hardcore Mechanics
- No safe spawn - temperature affects all biomes
- Continuous threat from environmental hazards
- Requires strategy and resource management
- Permadeath compatible

## Configuration

The mod includes comprehensive configuration options:

- **Blizzard Frequency**: Control how often blizzards occur
- **Temperature Drop Rate**: Adjust how fast it gets cold
- **Minimum Temperature**: Set the coldest possible temperature
- **Enable/Disable Frostbite**: Toggle damage from cold
- **Enable/Disable Permafrost**: Toggle block freezing

## Installation

1. Install Minecraft Forge 1.20.1
2. Place the mod JAR in your `mods` folder
3. Launch Minecraft

## Requirements

- Minecraft 1.20.1
- Forge 47.2.0 or higher
- Java 17+

## Development

Built with Forge MDK for Minecraft 1.20.1

### Building

```bash
./gradlew build
```

The compiled JAR will be in `build/libs/`

## Gameplay Tips

- Craft armor immediately for protection
- Build shelters with walls to reduce wind exposure
- Keep fires burning for warmth
- Monitor temperature warnings on HUD
- Blizzards are deadly - seek shelter immediately when one starts
- Stock up on food - cold increases hunger
